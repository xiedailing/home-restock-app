# 資料持久化（localStorage）討論稿

- 日期：2026-10-13
- 狀態：**已實作**（PR #27，`feat/persist-store`）。Q1、Q2 已定案（2026-10-13，皆採建議的選項 A）；Q3（示範前誰負責還原）與學校電腦實測仍待辦。
- 期限：2026-10-21 繳交，2026-10-22 示範（使用**已部署的網站**，在學校電腦上展示）。

## 1. 為什麼要做

目前所有資料都存在記憶體，重新整理頁面就會回到示範資料。示範時如果不小心重新整理，剛輸入的內容會消失。

老師只「建議」使用後端（MySQL／XAMPP／Python），不是評分必要條件，所以**不做後端**，改用瀏覽器的 localStorage。

## 2. 建議持久化的內容（`src/stores/items.js`）

| 內容 | 說明 | 備註 |
|---|---|---|
| `items` 用品 | 含補貨紀錄 `restockRecords`、提醒設定、計算基準、購買清單狀態、延後到期日、認購人 | 資料核心；購買清單的狀態都在 item 欄位裡，存 `items` 就一起保存 |
| `spaces` 空間 | 名稱、顏色、是否共享、成員、順序 | 拖曳排序會改變順序，所以要存 |
| `customCategories` 自訂分類 | 字串陣列 | 組員調整中，等完成後再接 |
| `departedSpaces` 已退出的空間 | 退出後保留給其他成員的資料 | 只影響用邀請碼（FAM-8888、COM-8888）重新加入的展示流程 |

## 3. 不持久化的內容

| 內容 | 原因 |
|---|---|
| `recentlyRemoved` 最近刪除 | 5 秒復原用，重新整理後沒有意義 |
| `today`、午夜計時器 | 由當下時間計算 |
| `inventorySpaceId` 我的用品目前篩選 | 規格明訂不持久化（ADD-05） |
| `shoppingCompletionOperations` 購買完成的復原記錄 | 是 Map，只供短時間復原 |
| Toast、Bottom Sheet 開關、各頁表單暫存 | 畫面暫態 |
| `SettingsView` 的 sessionStorage | 已有自己的機制，保留 |

## 4. 需要注意的風險

1. **示範資料的日期是相對「今天」產生的。** 存起來後隔天再開，日期會變舊，狀態可能全變成「補貨時間已過」。示範前必須還原一次示範資料。
2. **6 個預覽品項、「家庭／公司／旅行」空間、認購人「小明」是 store 建立時寫死塞入的。** 載入存檔時要整批取代，不能載入後又重複塞一次。
3. **邀請碼流程依賴 `departedSpaces`。** 還原後要保持一致，否則重新加入會重複。
4. **存檔格式要有版本號。** 版本不符或 JSON 損壞時回到示範資料，不能白畫面。
5. **學校電腦可能是無痕模式或禁用 localStorage。** 所有讀寫都要 try/catch，失敗時照常運作但不保存。**必須在學校電腦上實測。**
6. **多個分頁同時開啟時，後寫入者會覆蓋前者。** 示範只開一個視窗就沒問題；是否監聽 `storage` 事件同步，待決定（預設不做）。
7. **頭像上傳後是 512×512 的 PNG data URL**，可能數百 KB。localStorage 上限約 5MB，若要存 `profile` 要處理寫入失敗。

## 5. 需要你們決定的三件事

### Q1：`profile`（姓名、頭像）要不要一起存？

目前在 `src/stores/profile.js`，是模組層級的 reactive，不在 Pinia 裡。

| 選項 | 優點 | 缺點 |
|---|---|---|
| A. 一起存（建議） | 重新整理後姓名、頭像不會變回 `123` | 頭像 data URL 較大，要處理寫入失敗；需動 `profile.js`（組員的設定頁會用到） |
| B. 不存 | 不動 `profile.js`，範圍最小 | 重新整理後姓名、頭像會還原 |

你們的回答：**A（一起存）**。姓名與頭像另存一個 key，頭像寫入失敗不影響用品資料。

### Q2：還原示範資料的方式

| 選項 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| A. 網址參數（建議） | 開啟 `網址/?reset=1` 會清除存檔並載入示範資料 | 不用動組員的設定頁；示範前一個動作就能還原 | 要記得網址；需處理參數是否保留在網址上 |
| B. 設定頁按鈕 | 設定頁加「還原示範資料」 | 畫面上可見、不用記網址 | 要改設定頁（組員負責）；正式使用者也看得到 |

你們的回答：**A（網址參數）**。開啟 `網址/?reset=1` 會清除存檔、載入示範資料，並從網址移除該參數。

### Q3：示範前由誰負責還原一次、以及在哪台電腦還原？

localStorage 是**每台電腦、每個瀏覽器各自獨立**的。在自己電腦還原，不會影響學校電腦。

- 負責還原的人：**待決定**

  3. 示範流程跑一遍後，再還原一次（重新整理不會讓資料消失，所以排練留下的資料要記得清掉）
