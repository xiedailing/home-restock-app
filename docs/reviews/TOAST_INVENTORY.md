# 補補 Toast 清單

依目前程式整理（2026-10-18）。`{…}` 為實際操作資料，並非固定文案。

## 共用規則

- 成功：深色底、綠色成功圖示；錯誤／阻擋：深色底、紅色驚嘆號與文字，使用 `$toast-error-accent`。
- 網頁版：右上滑入／滑出，寬 280–360px、高 48–60px、圓角 16px、距頂部 28px；外側留白足夠時約 28% 位於內容內、72% 位於內容外，否則優先保留距螢幕右側 28px；手機版：原本底部位置，補貨頁的頁內提醒維持上方。
- 共用預設 8 秒；支援滑鼠停留／鍵盤聚焦時暫停，有動作時才顯示「復原／查看／邀請成員」。
- 邀請資訊複製提示為獨立實作，顯示 3 秒。
- 新增欄位必填、重名、名稱過長及部分儲存錯誤是表單內提示，沒有全部改成 Toast。

## 錯誤及阻擋提示（紅色）

| 入口／情境 | 文案／來源 |
| --- | --- |
| 加入空間，邀請碼不存在 | 邀請碼不存在 |
| 加入空間，人數上限 | 空間人數已滿 |
| 加入空間，重複加入 | 已經是成員 |
| 加入空間同步或存檔失敗 | Store 回傳的失敗訊息，例如「無法儲存空間同步，資料未變更。」 |
| 邀請碼空白／格式錯誤 | Store 有「請先輸入空間邀請碼／邀請碼格式不正確」；目前 UI 通常停用送出，未必會產生 Toast |
| 補貨頁點選他人已認領用品 | {認領者}已認領「{用品名稱}」，請先到購買清單接手認領 |
| 批次補貨失敗 | `batch.error.message`，依實際驗證／存檔錯誤而定 |
| 全域用品編輯失敗 | 編輯整合 API 回傳訊息；包含同步、存檔及單位變更失敗 |
| 分類／用品復原失敗 | 還原 API 的錯誤訊息，例如名稱衝突或儲存失敗 |
| 自訂單位復原失敗 | 「已有相同名稱的單位，無法復原。」等 API 回傳訊息 |
| 通知已讀／查看狀態儲存失敗 | 通知狀態儲存失敗，請稍後再試。 |
| 通知對應空間無法查看 | 此空間已不存在或無法查看 |
| 通知對應用品全部刪除 | 此通知的用品皆已刪除 |
| 通知對應用品部分刪除 | 此通知有部分用品已刪除 |
| 邀請資訊複製失敗（獨立 Toast） | 無法複製，請手動複製邀請資訊 |
