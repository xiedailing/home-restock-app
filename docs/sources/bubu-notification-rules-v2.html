通知頁面功能規則

整合通知入口、文字規則、60 秒合併、取消認領、已讀狀態、頁面跳轉、舊通知與資料保留。供 UI 設計、前端實作與測試時共同參考。

01｜通知入口與頁面

  1. 購買清單右上角頭貼替換為 bell.svg，維持尺寸、位置與 Soft UI 風格。
  2. 點擊鈴鐺，進入獨立「通知」頁，不使用下拉面板。
  3. 通知依建立時間由新至舊排列，卡片顯示文字、日期及類型 icon。
  4. 鈴鐺有未讀訊息時顯示小圓點，不顯示數字。
  5. 不做搜尋、分類篩選、手動刪除或全部清除。

02｜通知類型與對象

類型觸發情境接收者
該補貨了共享用品符合既有補貨提醒條件依原提醒設定的相關成員
已認領成員認領共享清單用品同空間其他成員
已接手接手其他成員認領的用品同空間其他成員
已補貨共享用品完成補貨同空間其他成員

個人空間的購買操作不產生共享通知；操作者不收到自己的操作通知；取消認領不發送通知；同一事件不得重複產生通知。

03｜通知文案規則

該補貨了

項數範例
1 項「家庭」的衛生紙該補貨了
2 項「家庭」有 2 項用品該補貨：衛生紙、洗衣精
3 項「家庭」有 3 項用品該補貨：衛生紙、洗衣精、垃圾袋
4 項以上「家庭」有 5 項用品該補貨：衛生紙、洗衣精…

已認領／已接手／已補貨

1～2 項：列出用品名稱；3 項以上：只顯示總數。

  • 小明已認領「家庭」的衛生紙。
  • 小明已認領「家庭」的衛生紙、酒精。
  • 花花已接手「家庭」5 項用品。
  • 小明已補貨「家庭」3 項用品。
通知文案使用事件發生時的成員、空間、用品資料；合併批次結束後，後續用品狀態改變不回寫歷史文字。

04｜1 分鐘內合併通知

同一操作者＋同一共享空間＋同一操作類型＋第一筆操作起 60 秒內，四個條件全部符合才能合併。

  • 認領、接手、已補貨分別合併，彼此不混合。
  • 固定 60 秒視窗，後續操作不延長視窗。
  • 同一用品在同批次僅計算一次；超過時間建立新通知。
  • 第一筆操作即建立通知，60 秒內可更新內容；結束後固定。
範例：10:00:00 衛生紙、10:00:25 洗衣精、10:00:50 垃圾袋，由小明在家庭認領 →「小明已認領『家庭』3 項用品。」

05｜取消認領規則

  1. 取消認領不產生新通知。
  2. 若仍在原通知 60 秒合併期內，從批次移除該用品；整批都取消則移除該通知。
  3. 合併期結束後取消，不修改舊通知。
  4. 點擊舊認領通知，進入共享清單並顯示最新認領狀態。

06｜卡片與已讀狀態

未讀：淺綠底、稍粗文字；已讀：白底、一般字重。卡片上不顯示未讀圓點，鈴鐺入口仍可有未讀提示點。

通知樣式示例
♧
「家庭」有 2 項用品該補貨：衛生紙、洗衣精
今天 10:30｜未讀
✓
小明已補貨「家庭」的衛生紙。
昨天 18:20｜已讀

只有點擊單筆通知才標記已讀；進入通知頁本身不會全部設為已讀。已讀項目仍可點擊。

07｜統一跳轉規則

通知類型目的地
該補貨了／已補貨我的用品 → 通知對應空間
已認領／已接手購買清單 → 共享清單 → 通知對應空間

無論一項或多項，都不直接進單一用品詳情；進入後顯示目前最新狀態。點擊舊通知不能重新執行認領、補貨或修改資料。

08｜舊通知與 Toast

補貨狀態更動不需要 Toast。 全部待補貨、部分已補貨、全部已補貨，或已補貨後再次進入待補貨，均正常跳轉、不顯示補貨狀態提示。通知記錄當時事件，列表顯示最新狀態。

特殊情況跳轉Toast
部分用品已刪除正常跳轉對應空間此通知有部分用品已刪除
全部用品已刪除留在通知頁此通知的用品皆已刪除
空間不存在或無權限留在通知頁此空間已不存在或無法查看

刪除不等於已補貨；若同時存在多種情況，優先提示無法進入的空間，再判斷用品刪除。一次點擊最多一則 Toast。無法跳轉的通知仍可標記已讀。

09｜無通知狀態

♧
目前沒有通知

有新的共享用品動態時，會顯示在這裡。

不需要新增操作按鈕。

10｜資料保留

  • 只保留最近 6 個月通知（已讀及未讀都適用）。
  • 到期自動移除，不影響用品、購買清單、補貨與認領紀錄。
  • 重新整理後仍保留未過期通知與已讀狀態。
  • 可在 App 啟動或開啟通知頁面時進行到期清理。

11｜開發範圍與限制

  • 沿用 Vue 3、Vue Router、Pinia、localStorage、Sass 與原有 Soft UI。
  • 通知資料包含 ID、類型、事件時間、操作者、接收者、空間 ID、用品 IDs、已讀狀態與合併視窗起點。
  • 同批次不重複計數；已讀狀態以接收者分別記錄。
  • 沒有後端、跨裝置即時同步；localStorage 只在各自瀏覽器儲存環境生效。
  • 不重做購買清單與我的用品功能，不讓通知影響實際補貨資料。
待實作時確認：若 60 秒內已有接收者讀過通知，又合併新用品，是否保留已讀狀態。本版暫採「保留已讀」，以減少未讀提示反覆跳動。

組員確認清單

可勾選用於討論；勾選僅保存在當前瀏覽器畫面，不會同步給其他人。
