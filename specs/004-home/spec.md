## 目標
首頁讓使用者一眼看到「現在該處理哪些用品」，並直接在卡片上加入購買清單或記錄補貨。取代目前的佔位畫面（`HomeView.vue`）。**「最近更新」卡顯示購買清單最近一筆已補貨（HOME-11）；不包含「暫時不用補貨」與推播。**

## 功能需求

### FR-401｜補貨提醒清單
- 列出所有空間中狀態為「該補貨了」與「補貨時間已過」的用品（001 FR-001）。購買清單中、未開啟提醒、不需補貨的用品不列入。
- 排序：補貨時間已過在前（過期越久越前），接著該補貨了（剩餘天數越少越前）；同天數維持新增順序。
- 標題徽章「N 項該補貨」，N ＝ 清單筆數；0 筆時不顯示徽章與【多選】。
- 0 筆：區塊內顯示 Empty State（Figma 1198:9734）。**只有完全沒有任何用品時**才加【新增用品】→ `/items/new`；已有用品時不放（Bottom Nav 已有新增入口；HOME-12）。

### FR-402｜補貨提醒卡片
- 內容：用品圖示（依狀態）、名稱、meta、狀態列、【＋ 加入清單】、右上「⋯」。
- meta：「空間・上次 M/D 補」；沒有補貨紀錄時只顯示空間（HOME-04）。
- 狀態列文字（不用驚嘆號，HOME-03；過期顏色 HOME-10）：
  - 補貨時間已過：「已超過預計補貨日 N 天」，淡紅底紅字（同我的用品狀態 Badge）
  - 該補貨了：「約 N 天後到預計補貨日」；剩 0 天為「今天是預計補貨日」（同 DET-10），淡橘底橘字（同我的用品狀態 Badge）
- 點卡片本體 → 用品詳情 `/items/:id`（Figma 註解：Popover 不再提供「查看用品詳情」）。

### FR-403｜加入清單
- 【＋ 加入清單】：同 003 FR-308（待買數量 1、加入日期今天）。
- 加入後狀態變「購買清單中」，卡片從補貨提醒移除（HOME-02）；待買摘要卡數字＋1。
- Toast「已加入購買清單」＋「查看」→ `/shopping`。

### FR-404｜「⋯」選單（Popover）
- 【記錄補貨】【暫時不用補貨】兩項（暫時不用補貨見 specs/005，FR-501；HOME-05 原本只有已補貨，已被 005 取代）。對齊「⋯」按鈕下方，點外面或 Esc 關閉。
- 【記錄補貨】→ 記錄補貨 Sheet（沿用 003 `RestockSheet`）→ 確認後同 003 FR-306；用品狀態變「不需補貨」而從清單移除；Toast「已記錄補貨」＋「復原」，復原後回到原位置。

### FR-405｜多選批次加入（004-B；HOME-06）
- 點【多選】→ 卡片右側出現勾選框（點卡片本體改為勾選，不進詳情；「⋯」與【加入清單】隱藏）、底部 Action Bar【取消】【加入清單（N 項）】、Bottom Nav 隱藏；標題右側改為「已選 N 項」。
- 未勾選時【加入清單】不可按。
- 確認 → 勾選的用品全部加入購買清單；Toast「已加入 N 項到購買清單」＋「查看」；離開多選。

### FR-406｜待買用品摘要卡
- 數字＝「我的清單」待買的用品數：個人空間用品加上自己認購的共享用品（與購買清單「全部補貨」範圍一致）；別人認購或尚未認購的共享用品不算（HOME-12，取代原「`shoppingList.length`」）。
- 0 項：不顯示數字與圖示，改為「目前沒有待買用品」，卡片無陰影（Figma `Soft Summary Card / 待買` Items = 0，988:2；HOME-08）。
- 1～3 項：顯示全部用品圖示；4 項以上：顯示 2 個圖示＋「+N」（N ＝ 總數 − 2；Figma Items = 4+，630:3219）。圖示依加入清單日期新到舊。
- 點擊 → `/shopping`。

### FR-407｜Toast 位置（HOME-07）
- `AppToast` 依目前頁面是否隱藏 Bottom Nav 決定位置：有 Nav 時在 Nav 上方（同我的用品 132px），沒有時維持 46px。

### FR-408｜最近更新卡（HOME-09、HOME-11）
- **資料來源**：購買清單「已補貨」區（006 FR-604）中，目前使用者完成的購買，取 `shoppingCompletedAt` 最新的一筆。一次完成多項（全部補貨）時仍只顯示最新一筆。
- **有資料**（Figma State=Default，992:2）：棕色時鐘圖示、右上箭頭、「最近更新」、粗體用品名稱 12px（單行，名稱最多 8 個中文字；過長以刪節號）、灰字「已補貨・HH:mm」（HOME-12：卡寬 100px 放不下「你已補」前綴）。有陰影、整張卡可點，前往購買清單「我的清單」頁籤（已補貨區段在該頁）。
- **時間格式**：完成當天「已補貨・HH:mm」，跨過午夜「已補貨・昨天」。
- **消失**：沿用已補貨區的 24 小時保留；到期自動回到空狀態。購買清單撤回補貨（取消勾選）時卡片同步回到空狀態或前一筆。
- **空狀態**（State=Empty，985:2）：灰色時鐘圖示、「最近更新」、「尚無更新紀錄」；無箭頭、無陰影、不可點擊。首頁卡寬 132，不放第二行「補貨後會顯示在這裡」。
- 其他成員的操作紀錄（001 D8）仍未做；有資料後再另訂。
