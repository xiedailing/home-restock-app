## 功能需求

### FR-401｜補貨提醒清單
- 列出所有空間中狀態為「該補貨了」與「補貨時間已過」的用品（001 FR-001）。購買清單中、未開啟提醒、不需補貨的用品不列入。
- 排序：補貨時間已過在前（過期越久越前），接著該補貨了（剩餘天數越少越前）；同天數維持新增順序。
- 標題徽章「N 項該補貨」，N ＝ 清單筆數；0 筆時不顯示徽章與【多選】。
- 0 筆：區塊內顯示 Empty State（Figma 1198:9734）＋【新增用品】→ `/items/new`。

### FR-402｜補貨提醒卡片
- 內容：用品圖示（依狀態）、名稱、meta、狀態列、【＋ 加入清單】、右上「⋯」。
- meta：「空間・上次 M/D 補」；沒有補貨紀錄時只顯示空間（HOME-04）。
- 狀態列文字（不用紅色與驚嘆號，001 D6；HOME-03）：
  - 補貨時間已過：「已超過預計補貨日 N 天」，淡暖橘底
  - 該補貨了：「約 N 天後到預計補貨日」；剩 0 天為「今天是預計補貨日」（同 DET-10），白底暖橘字
- 點卡片本體 → 用品詳情 `/items/:id`（Figma 註解：Popover 不再提供「查看用品詳情」）。

### FR-403｜加入清單
- 【＋ 加入清單】：同 003 FR-308（待買數量 1、加入日期今天）。
- 加入後狀態變「購買清單中」，卡片從補貨提醒移除（HOME-02）；待買摘要卡數字＋1。
- Toast「已加入購買清單」＋「查看」→ `/shopping`。

### FR-404｜「⋯」選單（Popover）
- 只有【已補貨】一項（「暫時不用補貨」另立規格，HOME-05）。對齊「⋯」按鈕下方，點外面或 Esc 關閉。
- 【已補貨】→ 記錄補貨 Sheet（沿用 003 `RestockSheet`）→ 確認後同 003 FR-306；用品狀態變「不需補貨」而從清單移除；Toast「已記錄補貨」＋「復原」，復原後回到原位置。

### FR-405｜多選批次加入（004-B；HOME-06）
- 點【多選】→ 卡片右側出現勾選框（點卡片本體改為勾選，不進詳情；「⋯」與【加入清單】隱藏）、底部 Action Bar【取消】【加入清單（N 項）】、Bottom Nav 隱藏；標題右側改為「已選 N 項」。
- 未勾選時【加入清單】不可按。
- 確認 → 勾選的用品全部加入購買清單；Toast「已加入 N 項到購買清單」＋「查看」；離開多選。

### FR-406｜待買用品摘要卡
- 數字＝購買清單中的用品數（`shoppingList.length`）。
- 0 項：不顯示數字與圖示，改為「目前沒有待買用品」，卡片無陰影（Figma `Soft Summary Card / 待買` Items = 0，988:2；HOME-08）。
- 1～3 項：顯示全部用品圖示；4 項以上：顯示 2 個圖示＋「+N」（N ＝ 總數 − 2；Figma Items = 4+，630:3219）。圖示依加入清單日期新到舊。
- 點擊 → `/shopping`。

### FR-407｜Toast 位置（HOME-07）
- `AppToast` 依目前頁面是否隱藏 Bottom Nav 決定位置：有 Nav 時在 Nav 上方（同我的用品 132px），沒有時維持 46px。
