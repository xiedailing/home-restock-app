# Feature 002｜新增用品頁（修訂版 1）

> 修訂日：2026-10-09。草案經使用者逐項確認（C1～C7、Q1～Q7），決策見 `docs/DECISION_LOG.md`（ADD-01～ADD-13）。
> 業務規則沿用 `specs/001-reminder-restock/spec.md`（以下簡稱 001），本規格只定義新增頁的畫面、互動與資料寫入。

## 目標
讓使用者從【新增用品】入口建立一筆用品，並在建立時決定是否開啟補貨提醒；開啟時寫入 001 FR-002 的計算基準。**不包含用品詳情頁、編輯用品、完成補貨 UI 與資料持久化。**

| Bottom Nav 中央【＋】 | `BottomNav.vue` → `App.vue`（原為 `alert`） | 目前在「我的用品」且篩選某空間時預帶該空間；其他頁面或「所有用品」為「個人」 |

- 路由：`/items/new`（name `add-item`），`meta.hideBottomNav: true`，頁面底部固定【建立用品】。

- 我的用品的空間篩選移到 items store（`inventorySpaceId`，`null` ＝ 所有用品），讓 `App.vue` 能讀到；仍不持久化（ADD-05）。

## 畫面結構（由上到下）
1. **App Bar**：返回鍵、標題「新增用品」。
2. **常用用品卡**（預設收合）：標題「常用用品」、說明「快速帶入名稱、分類與單位」；展開後說明改為「選擇後會自動帶入名稱、分類與單位。」，內容為固定高度 176px 的縱向捲動區。
3. **基本資訊 \***：用品圖示預覽、用品名稱、分類、補貨單位、所屬空間。
4. **補貨提醒**：開關「設定補貨提醒／系統會在接近需要補貨時提醒你。」；開啟時顯示「家裡目前有多少？」與「下一次預計什麼時候補貨？ \*」。
5. **底部 CTA**：【建立用品】，永遠可按（不以 disabled 表示未完成）。

## 功能需求

### FR-201｜常用用品
- 依現有用品插畫挑選；**分組即帶入的分類**（ADD-11），順序如下：

| 分組（＝分類） | 選項／單位 |
|---|---|
| 生活日用品 | 衛生紙／包、化妝棉／包、垃圾袋／捲、衛生棉／包 |
| 洗衣 | 洗衣精／瓶、洗衣膠囊／包、香氛豆／瓶 |
| 廚房 | 洗碗精／瓶、海綿／個、保鮮膜／條 |
| 個人護理 | 牙膏／條、沐浴乳／瓶、洗髮精／瓶 |
| 清潔 | 酒精／瓶、馬桶清潔劑／瓶 |
| 寵物用品 | 飼料／包、尿墊／包、貓砂／包 |

- 沒有對應插畫的選項顯示通用盒裝圖（Figma 17）；各選項的圖示見附錄 A。
- 點選項：帶入**名稱、分類、補貨單位**，圖示依 FR-203 重新判斷；**不帶入**數量、預計補貨日。已選項目顯示勾選；名稱被改成與該選項不同時取消勾選。
- 再選另一個常用用品會**覆蓋**名稱、分類、單位（Figma 19）。帶入後仍可手動修改。
- 選完不自動收合（Figma 02 選完仍為展開）。

### FR-202｜基本資訊欄位
| 欄位 | 必填 | 預設 | 互動 | 未填提示（柔和暖色，不用紅色） |
|---|---|---|---|---|
| 用品名稱 | 是 | 空，placeholder「例如：洗衣精、衛生紙、牙膏」 | 文字輸入；前後空白去除後不可為空；長度上限同空間名稱（中文算 2、英數算 1，上限 16，超過的字不輸入） | 請輸入用品名稱。 |
| 分類 | 是 | 未選，顯示「選擇分類」 | Selector Row，點擊在下方 inline 展開 pills，選完自動收合 | 請選擇分類，方便之後篩選用品。 |
| 補貨單位 | 是 | **不預設**，顯示「請選擇單位」 | inline 展開 pills：件、瓶、包、串、條、捲、個、自訂單位（ADD-13）；pills 下方說明「用於之後記錄「已補貨 1 瓶」這類資訊」 | 請選擇補貨單位。 |
| 　自訂單位 | 選「自訂單位」時必填 | 空，placeholder「例如：盒、袋、罐」 | 同區塊展開小 input；輸入後 row 顯示該單位 | 請輸入自訂單位。 |
| 所屬空間 | 是（有預設） | 依〈入口〉 | inline 展開 `spaces` 清單，最後一列「＋ 新增空間」（FR-207） | — |

- 分類選項沿用程式 `CATEGORIES`（生活日用品、清潔、洗衣、廚房、個人護理、寵物用品；「洗浴清潔」已改名為「清潔」，ADD-12），**沒有**「其他／未分類／新增分類」（ADD-03）。
- 單位不預設（ADD-04）；`createItem()` 的 `DEFAULT_UNIT` 不動，由表單強制選擇。
- 同一時間只展開一個 inline 區塊（分類、單位、空間）。

- 關鍵字對照：

| iconKey | 關鍵字 |
|---|---|
| laundry-detergent | 洗衣精 |
| tissues | 衛生紙、面紙 |
| dish-soap | 洗碗精 |
| trash-bags | 垃圾袋 |
| rubbing-alcohol | 酒精 |
| sponge | 海綿、菜瓜布 |
| cotton-pads | 化妝棉 |
| sanitary-pads | 衛生棉 |
| light-bulb | 燈泡 |

- 建立時把判斷結果存入 `iconKey`（無對應為 `null`）。詳情頁改名重判屬 Flow 03，不在本次範圍。

### FR-204｜補貨提醒區（對應 001 FR-002）
- 開關**預設開啟**。
- **開啟**時顯示：
  - 「家裡目前有多少？」：Quantity Stepper，預設 1、最小 1、無上限；數值後顯示目前單位（未選單位時只顯示數字）。為 1 時「−」變淡不可按。不標 \*。
  - 「下一次預計什麼時候補貨？ \*」＋說明「不需要很精準，只是先幫你把補貨需求留下來。」
    - 快選 pills：**下週**（＋7 天）、**兩週後**（＋14 天）、**下個月**（下個月同一天；該月沒有這天時取月底）（ADD-01）。空狀態不預選。
    - Date Row「預計補貨日」：空狀態顯示「選擇日期」；點擊開啟 Date Picker Sheet（標題「選擇預計補貨日」、月份切換、【完成】回填）。Sheet 是唯一的自訂日期入口。
    - 選中的日期等於某個快選結果時，該 pill 顯示選取；手動選其他日期時 pills 皆不選取。
    - **今天及以前的日期不可選**（001 D1-c、ADD-02）。Sheet 未選任何日期時【完成】不可按。
    - 未選日期按【建立用品】提示：「請選擇下一次預計補貨日。」
- **關閉**時隱藏數量與日期，改顯示「暫不設定也沒關係，之後可以在用品詳情頁再設定。」
- 開關切換**不清除**已填的數量與日期；但只有建立當下為開啟時才寫入。

### FR-205｜建立用品
- 按【建立用品】時檢查所有必填欄位；缺哪一欄就在該欄下方顯示提示，並捲動到第一個有問題的欄位。使用者修正該欄後，其提示即消失。
- 通過後呼叫 `itemsStore.addItem()`，寫入：

| 欄位 | 提醒開啟 | 提醒關閉 |
|---|---|---|
| name、category、unit、spaceId、iconKey | 表單值 | 表單值 |
| reminderEnabled | true | false |
| nextRestockDate | 選擇的日期 | null |
| reminderBaseDate（計算基準日） | 今天 | null |
| reminderBaseQuantity（計算基準數量） | 庫存量 | null |
| daysPerUnit（每單位可撐天數） | （預計日 − 今天）÷ 庫存量，保留小數 | null |
| cycleDays、lastRestockDate | null | null |
| inShoppingList、restockRecords | false、[] | false、[] |

- 例：2026-10-01 建立洗衣精、庫存 2、預計日 2026-10-31 → 基準（2026-10-01，2），每單位 15 天（同 001 驗收共同前提）。
- 建立後（ADD-06）：以 `router.replace` 回到我的用品（新增頁不留在瀏覽紀錄），顯示 Toast「已新增用品」（ADD-10）。
  - 我的用品篩選某空間且與新用品不同 → 切換到新用品的空間；為「所有用品」→ 維持。
  - 我的用品的分類、狀態篩選與搜尋本來就只存在頁面內，回到頁面時重置，新用品一定看得到。
  - 用品詳情完成後（Flow 03）改為進入詳情，詳情畫面以 Figma「[Draft] A｜用品詳情 / 補貨提醒開啟」為準（ADD-07）。

### FR-206｜返回與放棄
- 表單**未修改**（與進入時的初始值相同）→ 返回直接離開。
- 表單**已修改** → 顯示 Dialog「放棄新增？／你填寫的內容尚未建立，離開後將不會保留。」，按鈕【取消】【放棄新增】（危險色）。沿用 `InventoryView` 原生 `<dialog>` 樣式。
- 「已修改」包含：任一欄位有值或與預帶值不同、數量 ≠ 1、已選日期、提醒開關被關閉。
- 返回目標：有上一頁時 `router.back()`，否則回 `/inventory`。
- 透過 App 內導覽離開（含瀏覽器返回鍵）也走相同檢查（`onBeforeRouteLeave`）；建立成功後的跳轉不檢查。

### FR-207｜新增空間（ADD-08）
- 所屬空間展開清單最後一列「＋ 新增空間」，點擊開啟 Bottom Sheet。
- Sheet 內容複製 `SettingsAddSpace.vue`：標題「空間設定」、空間名稱（同名稱長度規則與錯誤提示）、多人共享開關與說明、空間代表色，主按鈕【新增空間】。Sheet 外觀沿用 `InviteMemberSheet.vue`（拖曳把手、往下滑或點背景關閉）。
- 建立成功：呼叫 `itemsStore.addSpace()`、關閉 Sheet、自動選取新空間並收合空間清單、顯示 Toast「已成功新增空間」（沿用設定頁文字與淺色 Toast 樣式）。
- 取消或關閉 Sheet：不建立空間，所屬空間不變。
- 設定頁的新增空間頁不修改（組員負責）。

### FR-208｜我的用品分類篩選：預設分類固定顯示，其他分類有用品才顯示（ADD-09）
- **預設分類**一律顯示：生活日用品、清潔、洗衣、廚房、個人護理（Figma 我的用品分類篩選 834:5231、用品詳情分類選擇 902:9485；程式 `DEFAULT_CATEGORIES`）。
- 預設分類以外的分類（目前只有「寵物用品」）只在**目前空間篩選範圍內**至少有一筆用品時顯示。
- 順序依 `CATEGORIES`；「全部」永遠顯示。新增用品頁的分類選擇仍顯示全部 6 類。
- 搜尋與狀態篩選不影響 pills 是否顯示（避免輸入時 pills 跳動）。
- 目前選取的非預設分類因切換空間或刪除而沒有用品時，自動回到「全部」。

## 資料模型變更（`src/models/item.js`）
- `createItem()` 新增三個欄位（預設 `null`）：`reminderBaseDate`、`reminderBaseQuantity`、`daysPerUnit`。
- 新增 `COMMON_ITEM_GROUPS` 常數（FR-201、附錄 A）、`ITEM_ICON_KEYWORDS` 與純函式 `matchItemIconKey(name)`（FR-203）。
- `UNITS` 新增「捲」「個」（ADD-13）；自訂單位直接存字串於 `unit`。
- **不修改** `completeRestock()`、`MIN_CYCLE_DAYS`、`REMIND_WITHIN_DAYS`（屬 001 的程式落地，另行處理）。
