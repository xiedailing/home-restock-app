# 我的用品｜購買清單標記 設計預覽

> 日期：2026-10-17。對應 `specs/010-inventory-list/spec.md`，決策見 `docs/DECISION_LOG.md` 的 UT-35。

## 這是什麼
可用瀏覽器開啟的 HTML 預覽，用來**對照畫面**，不是可以直接搬進專案的程式碼。需要連網（字型與 Font Awesome 走 CDN），並且要放在 repo 內開啟（預覽用相對路徑讀 `src/assets/` 的用品圖示，單獨複製出去會破圖）。

| 檔案 | 內容 |
|---|---|
| `inventory-list-v4.html` | 「我的用品」列表。依序是：① 現在、② ～ ⑥ 方案 A、⑦ ～ ⑪ 方案 B、⑫ ～ ⑮ 方案 C、⑯ ～ ⑳ **方案 A+（定案）** |
| `item-detail-badge-v1.html` | 用品詳情頁右上角標記：現在 vs 新規則（四種組合、名稱很長、360px 窄螢幕）、列表與詳情的規則對照 |

## 方案比較（列表）
| 方案 | 標記位置 | 名稱 | 結論 |
|---|---|---|---|
| A | pill 前面的圓圈 | 最多 2 行 | 圓圈排成靠右一欄，掃描最快；單獨一個圓圈沒有文字，要靠聯想 |
| B | 用品名稱後面 | 單行 | 位置隨名稱長短變動，要逐列找；名稱只剩約 8 個字 |
| C | pill 前面的圓圈 | 單行 | 名稱只剩約 8 個字，沒有比 B 好讀 |
| **A+** | A，但「沒到補貨期、已在清單」改顯示綠色「購買清單中」pill（帶同一個圖示） | 最多 2 行 | **定案**：每種狀態都不用猜，最差情況不比 A 擠 |

## 使用時要注意
- **行為以規格為準。** 預覽與規格不一致時，照 `spec.md`。
- **樣式要改用專案的 token。** 預覽 `:root` 的 CSS 變數對應 `src/assets/scss/_tokens.scss`（例如 `--primary` 對 `$primary-green`、`--primary-subtle` 對 `$primary-subtle`），不要複製預覽裡的色碼。
- **圖示是 Font Awesome `fa-clipboard-list`**，與 `BottomNav.vue` 同一個，實作時不需要新增圖檔。
- **預覽刻意簡化的地方**：頁首、搜尋、類別 pills、底部導覽只是示意；詳情頁只畫到「基本資訊」；用品資料是示範用的假資料。
