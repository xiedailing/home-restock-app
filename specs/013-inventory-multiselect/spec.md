# Feature 013｜我的用品：長按多選、批次加入購買清單（草案）

> 草案日：2026-10-18。決策 UT-43 見 `docs/DECISION_LOG.md`〈決策紀錄｜可用性測試修改（2026-10-15）〉。
> 狀態標記沿用 `specs/010-inventory-list/spec.md`；加入購買清單的 store 行為沿用 `specs/001-reminder-restock/spec.md` FR-006 與 `stores/items.js` 的 `addToShoppingList`；Toast 與復原沿用 `specs/003-item-detail/spec.md` DET-07 與 UT-10（8 秒、觸碰暫停）。
> 這是「我的用品」多選的第二次設計：首頁的多選（`specs/004-home/spec.md` FR-405）隨首頁移除，本規格把同樣的概念放到「我的用品」，進入方式改為長按。

## 目標
使用者在「我的用品」一次挑出多個用品加入購買清單，不必逐一點進詳情再按「加入清單」。UT-32 把這件事列為未來展望，本規格將它納入。

## 名詞
- **選取模式**：長按任一張卡片後進入的狀態；離開前，一般的點卡片進詳情、左滑刪除、底部導覽都暫時改變。
- **已選項目**：選取模式中被勾選的用品。
- **已在清單**：`item.inShoppingList === true`。

## 功能需求

### FR-1301｜進入選取模式
- 在列表的卡片上**長按約 0.5 秒**進入選取模式，該卡片成為第一個已選項目。長按期間手指或滑鼠位移超過 8px、或已開始垂直捲動，視為取消長按（不進入）。
- 長按放開後瀏覽器補發的 click 要忽略，不進入詳情（同 `ItemListRow` 拖曳後忽略一次 click 的做法）。
- 進入時，已左滑展開的列先收回。
- 只在「我的用品」有列表時可進入；空間沒有用品、搜尋 0 筆的空狀態沒有卡片，不受影響。
- 桌機滑鼠按住 0.5 秒同樣進入。不新增其他入口（見「未決與不做」）。

### FR-1302｜選取模式的畫面
- **頁首**：LOGO、空間膠囊、鈴鐺暫時隱藏，改為左側的「已選 N 項」（N 為已選項目數，0 時顯示「已選 0 項」）。
- **搜尋欄與類別 pills**：保留可用，方便先篩選再勾選。搜尋或類別改變時，**不在目前結果內的已選項目取消選取**，所以「已選 N 項」永遠等於畫面上勾著的數量。
- **卡片**：每張卡片最前方（用品圖示左邊）出現 24px 選取圓圈。未選：灰色邊框空圈；已選：綠色（`$primary-green`）實心圈加白色勾勾，卡片底色轉淡綠（`#eff6ee`）。卡片右側的箭頭隱藏，狀態標記（FR-1001）照常顯示。
- **點卡片**：選取／取消選取，**不進詳情**；左滑刪除暫停（不展開刪除鈕）。
- **底部**：底部導覽（含「＋」鈕）整個隱藏，換成兩顆按鈕：左邊【取消】（白底、灰邊）、右邊【加入購買清單】（綠底、白字、前面有 `fa-clipboard-list` 圖示，填滿剩餘寬度）。兩顆按鈕高 56px，區塊高度與導覽列相同（68px），底部留白不變（`$bottom-nav-offset`），其上方的漸層與 Toast 位置不變。
- 空間：選取模式中不能切換空間（膠囊已隱藏）。

### FR-1303｜選取與取消
- 已選 0 項時【加入購買清單】停用（灰色，`disabled`）；【取消】仍可按。
- **取消選取最後一張卡片不會自動離開選取模式**，要按【取消】才離開。
- 【取消】：清除所有已選項目，回到一般的我的用品頁（導覽列、頁首恢復）。不顯示確認視窗。
- 其他離開方式：按 Esc、離開頁面（切換分頁或進入其他路由）都等同【取消】，並還原底部導覽的顯示狀態。

### FR-1304｜加入購買清單
- 按【加入購買清單】：
  1. 已選項目中，**已在清單的略過**；其餘逐一呼叫 `addToShoppingList`（待買數量 1、加入日期今天、取消延後、清除認領）。
  2. 離開選取模式；卡片的狀態標記依 FR-1001 立即更新（例如「沒到補貨期」變成綠色「購買清單中」pill、「該補貨了」多出圓形清單標記）。
  3. 顯示 Toast「已加入 N 項到購買清單」＋「復原」，N 為**實際新加入**的數量（略過的不計）。
- 已選項目**全部**都已在清單：不改任何資料，離開選取模式，Toast 顯示「所選用品都已在購買清單」，沒有「復原」。
- 略過已在清單的用品，是為了不覆蓋共享空間他人已有的認領（`addToShoppingList` 會清除 `shoppingClaimantId`）。

### FR-1305｜復原
- Toast 的「復原」把**這一批新加入**的用品還原成加入前的樣子（加入前用 `snapshotItem` 逐一存下，復原時用 `restoreItem`），略過的用品不動。復原後卡片標記同步還原。
- Toast 規則沿用：8 秒（UT-10）、觸碰、滑鼠停留或聚焦時暫停倒數；新的 Toast 取代舊的，舊的不能再復原（DET-07）；離開頁面即失效。
- 復原不重新進入選取模式。

### FR-1306｜Toast 外觀
- 沿用既有深色 Toast（`AppToast`，Figma `Feedback / Toast` 的 Type=With Action）：綠色勾勾圖示、白色訊息、右側淡綠色動作文字「復原」。位置在底部導覽列正上方（`$toast-bottom`）；加入完成後導覽列已恢復，不會被蓋住。

### FR-1307｜無障礙
- 長按沒有鍵盤與螢幕閱讀器的等價操作，所以這個功能目前**不保證**鍵盤使用者可用（見「未決與不做」）；進入選取模式後，鍵盤可以操作：卡片可聚焦，Enter／空白鍵切換選取，Tab 可到【取消】【加入購買清單】，Esc 離開。
- 選取模式中每張卡片為 `role="checkbox"` 並帶 `aria-checked`，圓圈 `aria-hidden`；「已選 N 項」放在 `aria-live="polite"` 區域，數字改變時被朗讀。
- 勾選狀態不只靠顏色：有勾勾圖示與底色兩種表達。

## 驗收
1. 長按「洗衣精」約 0.5 秒：進入選取模式，頁首為「已選 1 項」，洗衣精前面是綠色勾勾、底色淡綠，底部是【取消】【加入購買清單】；放開後不會進入詳情。
2. 短按（一般模式）仍進詳情；垂直捲動列表不會誤觸長按；左滑仍可展開刪除。
3. 選取模式中點其他卡片：勾選與取消勾選，「已選 N 項」跟著變；點卡片不進詳情；左滑不展開刪除鈕。
4. 取消選取到 0 項：【加入購買清單】變灰不可按，仍在選取模式；按【取消】才離開，所有選取清除。
5. 選取「洗衣精」「海綿」「洗碗精」（洗碗精已在清單）按【加入購買清單】：離開選取模式；洗衣精出現圓形清單標記、海綿變成綠色「購買清單中」pill、洗碗精不變；Toast「已加入 2 項到購買清單」。
6. 按 Toast「復原」：洗衣精、海綿回到加入前的標記；洗碗精不受影響；購買清單頁同步少 2 項。
7. 8 秒內不操作 Toast 消失；觸碰 Toast 時暫停倒數；再次批次加入，舊 Toast 的復原失效。
8. 只選已在清單的用品按加入：Toast「所選用品都已在購買清單」，無「復原」，資料不變。
9. 選取後在搜尋欄輸入文字，使某已選項目不在結果內：該項被取消選取，「已選 N 項」同步減少。
10. 選取模式中按 Esc、或切換到別頁再回來：回到一般模式，底部導覽顯示正常。
11. 共享空間：選取他人已認領的用品加入清單時被略過（本來就在清單），認領不被清除。
12. 窄螢幕（360px）：圓圈、名稱、狀態標記可並存；名稱最多 2 行再省略。
13. 回歸：刪除與復原、詳情「加入清單」、購買清單頁不變；主控台無錯誤。

## 未決與不做
- **沒有「選取」入口按鈕**：長按不容易被發現，且鍵盤與螢幕閱讀器使用者無法進入。預設不做；若可用性測試發現沒人找到，可在列表上方加一個「選取」文字按鈕作備援。
- 不做：批次刪除、批次記錄補貨、全選、跨空間選取、拖曳框選。
- 篩選改變時剔除已選項目（FR-1302）是設計時的預設，尚未在 Figma 畫出此情境；若覺得意外，可改成「保留選取、數字包含被篩掉的項目」。
- 圓圈在左側使名稱區變窄約 38px、箭頭隱藏後狀態標記往右靠，長名稱較容易折行；以 390 與 360 寬實機確認。
- 設計稿只有手機版；桌機版（寬螢幕）的選取模式與底部按鈕位置未畫。
