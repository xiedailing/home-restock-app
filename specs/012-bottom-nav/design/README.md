# 底部導覽與「＋」選單 設計預覽

> 日期：2026-10-17。對應 `docs/DECISION_LOG.md` 的 UT-37（這個改動夠小，沒有另開 spec）。

## 這是什麼
可用瀏覽器開啟的 HTML 預覽（`bottom-nav-v2.html`），用來**對照畫面**，不是可以直接搬進專案的程式碼。需要連網（字型與 Font Awesome 走 CDN），並且要放在 repo 內開啟（預覽用相對路徑讀 `src/assets/` 的用品圖示，單獨複製出去會破圖）。

| 畫面 | 內容 |
|---|---|
| ① | 現在：選單關閉（導覽列佔 116px） |
| ② | 現在：點「＋」（選單與列表卡片同色、只有字） |
| ③ | 新：選單關閉（導覽列佔 102px） |
| ④ | 新：點「＋」（遮罩、圓形圖示、「記錄補貨」「新增空間」） |
| ⑤ | 新：Toast 位置（導覽列上方 16px） |
| ⑥ | 尺寸對照表 |
| ⑦ | 特寫：白圈有無與「新增空間」圖示候選（已決定：無白圈、資料夾＋） |

## 版本紀錄
v1 的「＋」鈕縮成 52px、底部留白 24px；使用者認為「＋」鈕大小剛好、是旁邊長條太高，v2 改成只縮膠囊，並把選項改名「記錄補貨」（與用品詳情的按鈕一致）、「新增空間」圖示由人像改資料夾＋、「＋」鈕拿掉白圈。

## 使用時要注意
- **樣式要改用專案的 token**：導覽列尺寸是 `$bottom-nav-height`（68px）與 `$bottom-nav-offset`（34px），`$toast-bottom` 由它們算。
- 預覽的頁面內容（頁首、搜尋、類別 pills、列表）只是示意，用品資料是示範用的假資料。
