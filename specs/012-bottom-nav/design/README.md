# 底部導覽與「＋」選單 設計預覽

> 日期：2026-10-17。對應 `docs/DECISION_LOG.md` 的 UT-37（這個改動夠小，沒有另開 spec）。

## 這是什麼
可用瀏覽器開啟的 HTML 預覽（`bottom-nav-v7.html`），用來**對照畫面**，不是可以直接搬進專案的程式碼。需要連網（字型與 Font Awesome 走 CDN），並且要放在 repo 內開啟（預覽用相對路徑讀 `src/assets/` 的用品圖示，單獨複製出去會破圖）。

| 畫面 | 內容 |
|---|---|
| ① ② | 現在：選單關閉／點「＋」（選單與列表卡片同色、只有字） |
| ③ ④ | 新：選單關閉／點「＋」（遮罩、圓形圖示、「記錄補貨」「新增空間」） |
| ⑤ | 新：Toast 位置（導覽列上方 16px） |
| ⑥ | 尺寸對照表 |
| ⑦ | 特寫：白圈有無與「新增空間」圖示候選（已決定：無白圈、資料夾＋） |
| ⑧～⑫ | 浮動感比較：舊的、現在的、加強陰影、背景色漸層、兩者並用（比較用，最後沒採用） |
| ⑬～⑰ | 底部漸層與玻璃：⑬ 現在、⑭ 玻璃＋參考圖漸層、⑮ 不透明＋近黑 16%、⑯ 不透明＋淺暖灰 28%、**⑰ 不透明＋淺暖灰 20%（採用）** |

## 決定
- 「＋」選單加遮罩、圓形圖示；「記錄補貨」用＋、「新增空間」用資料夾＋。
- 導覽列只縮膠囊（82→68px）；「＋」鈕維持 56px 並拿掉白圈；底部留白維持 34px。
- 螢幕最底部加**淺暖灰漸層**（畫面 ⑰）：高 135px，顏色 `rgba(140,136,127)`，最深 20%、膠囊頂端 7%、頂端 0。
- **不做玻璃效果**：米色配色下模糊前後差異很小，看不出來，卻要承擔 `backdrop-filter` 的瀏覽器支援與效能風險；參考圖（Instagram）的折射效果網頁也做不到。

## 版本紀錄
v1 的「＋」鈕縮成 52px、底部留白 24px；使用者認為「＋」鈕大小剛好、是旁邊長條太高，v2 改成只縮膠囊，並把選項改名「記錄補貨」、「新增空間」圖示由人像改資料夾＋、「＋」鈕拿掉白圈。實作後使用者回報導覽列浮動感不見了：v3 比較加深陰影與背景色漸層；v4～v5 做玻璃（效果太淡）與黑色漸層；v6 照使用者提供的參考照片量數字重做；v7 因不透明膠囊不會被漸層壓暗，加入「淺暖灰＋較高透明度」，最後採用 ⑰。

## 使用時要注意
- **樣式要改用專案的 token**：導覽列尺寸是 `$bottom-nav-height`（68px）與 `$bottom-nav-offset`（34px），`$toast-bottom` 與底部漸層高度都由它們算。
- 預覽的頁面內容（頁首、搜尋、類別 pills、列表）只是示意，用品資料是示範用的假資料。
- 預覽 ⑬～⑰ 是「內容往上捲、穿過導覽列後面」的狀態；有顏色的 pill 刻意放在膠囊後面。
