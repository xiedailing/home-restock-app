# 補貨明細（用品詳情改版）設計預覽

> 日期：2026-10-17。對應 `specs/011-item-detail-revision/spec.md`，決策見 `docs/DECISION_LOG.md` 的 UT-36。

## 這是什麼
可用瀏覽器開啟的 HTML 預覽（`item-detail-v8.html`），用來**對照畫面**，不是可以直接搬進專案的程式碼。需要連網（字型與 Font Awesome 走 CDN），並且要放在 repo 內開啟（預覽用相對路徑讀 `src/assets/` 的用品圖示，單獨複製出去會破圖）。

| 畫面 | 內容 |
|---|---|
| ① | 現在的用品詳情（對照） |
| ② | 該補貨了＋已在清單 |
| ③ | 沒到補貨期＋已在清單 |
| ④ | 只有該補貨了 |
| ⑤ | 提醒未開啟 |
| ⑥ | 只有 1 筆紀錄（卡片、沒有開關列、「再補貨 1 次後預估」） |
| ⑦ | 今天是預計補貨日（「（今天）」後綴） |
| ⑧ | 點右上角「⋯」（用品管理、刪除用品） |
| ⑨ | 名稱很長（360px） |
| ⑩ | 資訊去向與字級對照表 |

## 認領規則預覽（`claim-block-v1.html`，2026-10-17，UT-40、UT-41）
另一份預覽，示範共享清單的認領規則在補貨明細與記錄補貨頁的樣子（詞彙一律用「認領」）。

| 畫面 | 內容 |
|---|---|
| ① | 現在：別人已認領，頁面看不出來、「記錄補貨」可直接按（對照） |
| ② | 別人已認領：多一列「認領狀態：小明已認領」，主要鈕換成「接手認領」 |
| ③ | 按「接手認領」後：Toast 可復原，列變「我已認領」，主要鈕換回「記錄補貨」 |
| ④ ⑤ | 自己已認領、尚未認領：都可以直接記錄補貨 |
| ⑥ | 名字很長（360px）：整行寬度，完整顯示 |
| ⑦ ⑧ ⑨ | 記錄補貨頁：被別人認領的格子標記、點擊後的 Toast、對照現在 |

行為以 `spec.md` 的 FR-1110 與 `specs/009-restock-record/spec.md` 的 FR-915 為準。預覽裡「認領狀態」列的淡綠底只是標出新增，實作時沒有這個底色。

## 版本紀錄
預覽從 v1 做到 v8，主要的來回：v2 曾把狀態只放在提醒卡，使用者認為「列表有、詳情沒有」很奇怪，v3 起改為保留在摘要卡（與列表一致）；v3 加入設定頁風格的開關列與 Figma 按鈕；v4 加「⋯」選單；v5 預計補貨日暖橘色；v6 「（今天）」後綴與紀錄箭頭；v7 曾畫過延後提醒（暫時不用補貨），v8 因決定不做而拿掉。

## 使用時要注意
- **行為以規格為準。** 預覽與規格不一致時，照 `spec.md`。
- **樣式要改用專案的 token。** 預覽 `:root` 的 CSS 變數對應 `src/assets/scss/_tokens.scss`，不要複製預覽裡的色碼。
- **按鈕**：照 Figma「Actions」元件（902:7077）；次要鈕字色 `#244f34` 是 Figma 的 `color/brand/dark`。
- **預覽刻意簡化的地方**：頁首以下才是實作範圍，狀態列、「⋯」選單只是示意；開關、箭頭沒有互動；用品資料是示範用的假資料。
