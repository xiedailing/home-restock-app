# Feature 007｜設定（草案）

> 草案日：2026-10-11；2026-10-12 對照最新 main `90531e4` 的 D4-c 更新分歧表。依 main `b7295cb` 整理已完成畫面及互動，包含設定主頁、個人檔案、空間管理與用品管理。沿用 001、003 與現有共用資料，不修改既有規格或 tokens；分歧記於文末，先保留。

## 目標
讓使用者管理個人檔案、提醒選項、空間與用品分類。畫面展示行為與已接通的資料操作分開描述，不將未接登入、通知或多人服務視為已完成。

## 畫面結構
1. 設定主頁：標題、個人頭貼與暱稱／帳號、提醒設定、空間管理入口、用品管理入口、登出。
2. 個人檔案：返回、頭貼操作、登入帳號與可編輯暱稱，無儲存按鈕。
3. 空間管理：我的空間、拖曳排序、新增空間、邀請碼加入。
4. 空間新增／編輯：名稱、多人共享、代表色；編輯另有成員、邀請與退出。
5. 用品管理：系統分類、自訂分類及新增欄；分類內用品清單及刪除操作。

## 功能需求

### FR-701｜設定主頁與提醒
- 標題沿用我的用品的設定值，卡片底色與圓角引用 tokens，分隔線留左右空間。
- 頭貼與個人檔案資料共用；頭貼圓底使用現有淺綠色。
- 通知預設開；補貨建議與購買清單提醒預設 5 天。
- 補貨建議選项：提前 5 天、提前 7 天、自行設定、不要提醒。
- 購買清單提醒選項：加入後 5 天、加入後 7 天、自行設定、不要提醒。
- 自行設定顯示輸入 placeholder，不預填任意天數；只接受數字，有效值為正的安全整數，填入後顯示在原自行設定位置。
- 點空白處收合選項；兩種選單上下距離相同，分隔線不貼齊卡片。
- 通知關閉時摘要顯示灰色「不要提醒」，保留原選項；開啟後恢复原設定。
- 兩項手動選不要提醒，通知自動關閉；任一改回提醒，通知開啟。單項不要提醒時該項摘要灰色。
- 現況為頁面 ref，不是已接通知服務或共用計算門檻。

### FR-702｜暱稱與帳號
- 登入帳號、暱稱前方不放 icon；帳號僅顯示。
- 暱稱先顯示文字與灰色鉛筆；點鉛筆才變輸入框，無獨立編輯彈窗或儲存按鈕。
- 名稱沿用共用限制：ASCII 權重 1，其他字元權重 2，額度 16；即最多 8 中文或 16 ASCII 字元。計數顯示整數，不出現 .5。
- 输入處理須保留中文 IME 選字與刪除；超額提示邊框，计數放輸入框內。空白處理沿用頁面現有驗證，不擴大修改其他名稱規則。
- 成功更新 profile，toast 沿用 tokens。暱稱同步成員自己的名稱等 profile 使用處。

### FR-703｜頭貼
- 相機按鈕圖示依使用者指定 `fa-regular fa-camera`，置中圓形按鈕。
- 選項以平面視窗呈現，依有無自行上傳頭貼提供對應操作。
- 上傳最大 5 MB；超出時頭貼下方提示「圖片大小不可超過 5 MB，請重新選擇。」
- 選照片後可拖曳調整裁切位置與縮放，確認才更新；取消保留原圖。
- 共用 profile 的頭像會同步設定主頁、購買清單與目前使用者成員頭貼。
- 設定入口返回設定；購買清單以 `from=shopping` 進入則返回購買清單。

### FR-704｜空間列表、加入與排序
- 我的空間列表用代表色及名稱；非滑刪列的分隔線保留共用左右 inset。
- 長按進入排序，左側 grip，支援滑鼠與觸控拖曳；拖曳底色與分類排序一致、矩形無圓角，點空白結束。
- 排序同步 store 空間順序及購買清單空間篩選標籤。
- 邀請碼格式為 3 個英文字母、連字號、4 數字，例如 `FAM-8888`；未符合時加入停用。
- 加入結果為展示用本機邏輯，不代表已接驗證碼服務；成功／失敗用 toast。

### FR-705｜新增／編輯空間
- 新增、私人、共享卡片使用一致列高／分隔線與間距邏輯，獨有說明才增加高度。
- 名稱限制同 FR-702，禁止空白；編輯點鉛筆進入原位輸入，清除 icon 清空輸入但保留編輯、原名 placeholder。
- 共享名稱提示「此名稱會同步顯示給其他成員」，計數在輸入框內；修改名稱成功用 toast。
- 多人共享預設關閉，不另顯示私人／共享標籤。新增或可切換空間開啟時顯示「開啟後可邀請成員加入，最多 10 人。」並動畫撐高，靠左、在線上方。
- 初始個人空間不可切共享，該列顯示「-」，也不可退出。
- 共享有其他成員時開關仍顯示，但灰色不可更改；所有成員均可編輯名稱與代表色，不採擁有者專屬編輯。
- 代表色沿用 `SPACE_COLORS`；選邊緣灰色自動慢速捲到完整可見，再進編輯也保持選色可見。
- toast：「空間代表色已更新」、名稱更新提示、「多人共享已開啟／已關閉」。
- 空間名在卡片或空間標籤最多 4 字＋…，不截斷儲存的名稱。

### FR-706｜成員、邀請與退出
- 人數「N / 10」；滿額在人數左側顯示「已達上限」淡紅標籤，底色引用現有 `$feedback-error-subtle`。
- 成員頭貼 32px 與淺綠圓底；自己跟 profile 更新。超過 4 人採收合，初始顯示 3 人。
- 私人空間顯示「此為個人專屬空間，無法邀請其他成員加入」，不顯示邀請按鈕；切共享後還原按鈕，滿額停用。
- 邀請成員開 bottom sheet，上方拖曳線；示範邀請碼 `ABC-0000`。複製有按壓凹陷及「邀請碼已複製」toast。
- 新增共享成功返回管理，toast 附「邀請成員」；點後進該空間編輯再開邀請 sheet。
- 退出確認：有其他成員「退出後將無法查看此空間內容，需重新受邀才能加入。」；唯一成員「你是唯一成員，退出後此空間與所有資料將永久刪除。」
- 按鈕取消／退出，取消無預設綠框；成功以退出 icon toast 顯示「已退出OO空間」。

### FR-707｜用品分類管理
- 系統分類共用 `itemCategories` 資料，不另外複製名稱；數量以 store 用品實際分類計數，0 項系統分類隱藏。
- 自訂分類說明「可自行新增分類並管理用品」放小標下方。新增欄內有计數，名稱額度同 FR-702。
- 輸入時即偵測與現有系統／自訂分類重名：紅褐框、卡片內提示「已有重複分類名稱」；新增成功 toast。
- 自訂分類左滑露出刪除，原標題垃圾桶／批次刪分類方式已移除。可滑刪列分隔線貼齊卡片；不可滑刪列保留 inset。
- 長按自訂分類進拖曳排序，動畫與空間排序一致，點空白結束。
- 刪分類確認「刪除分類？」；0 項「即將刪除「分類」。」，有用品「「分類」內的N項用品也會一併刪除，無法復原。」
- 目前一次刪一分類，連同分類內用品實體刪除，與購買清單僅移除清單項目不同。

### FR-708｜分類內用品
- 用品列靠左、不放用品圖示；空間標籤在名稱左側，間距 10px，字小於名稱，颜色随空間代表色。
- 空分類使用共用 `generic-item-in-stock` 素材呈現空狀態。
- 用品可左滑刪除，也可點標題右側垃圾桶進多選；垃圾桶樣式沿用品詳情。
- 多選時右上改取消；底部固定「已選取 N 項」＋刪除，不隨清單長度改位置；未選停用。
- 選框 24px、圓角 6px，未選白色、選取綠底白勾。
- 單項個人文案：「「用品」將從「空間」空間刪除，補貨提醒與紀錄也會一併刪除。」；共享：「將從「空間」空間刪除並同步所有成員，相關紀錄與提醒將一併刪除。」
- 多選全個人：「相關補貨提醒與紀錄將一併刪除。」；含共享：「相關補貨提醒與紀錄將一併刪除，共享用品也會從所有成員的清單刪除。」
- 用品刪除有長條 toast＋復原，與我的用品使用同一份 store；分類列已有用品詳情路由串接，依頁面既有返回規則處理。

### FR-709｜視覺與退出登入
- 優先引用现有 tokens，卡片陰影沿 App.vue 共用設定與既有頁面引用方式；不因本文新增 token。
- 登出按鈕引用 danger subtle 樣式；確認後現況提示「登出功能尚未串接登入服務。」
- 共用轉場以目前 App.vue 啟用條件為準，不宣稱全路由都已套用；頭像跨購買清單轉場未啟用。

- profile：暱稱、頭貼與帳號展示；沒有正式登入同步或跨裝置保證。
- items store：空間、成員、用品與分類；展示資料／邀請碼服務未接後端。
- 提醒設定目前在 `SettingsView.vue` 本地 ref；通知開關不是系統通知權限。
- 程式範圍：上述 `Settings*.vue`、`stores/profile.js`、`stores/items.js`、`models/space.js`、`models/itemCategories.js`、`SpaceColorPicker.vue`、`SwitchTrack.vue`、`SpaceTag.vue`。
- 本次規格文件分支不修改以上程式、tokens、App.vue 或 001～005。
